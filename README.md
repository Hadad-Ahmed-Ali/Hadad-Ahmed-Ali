## 📂 Projets Data

### Pipeline Data Hub'Eau — Analytics Engineering

Conception d'un pipeline de données relatives à la **qualité de l'eau potable en France**, à partir de l'API publique Hub'Eau.

**Architecture du projet :**

`API Hub'Eau → Python → BigQuery → dbt → Power BI`

**Réalisations :**

- Extraction de données pour **12 paramètres** via API REST et Python.
- Ingestion des données dans **BigQuery sur GCP**.
- Modélisation SQL avec **dbt (STG, ODS, dimensions et faits)**.
- Mise en place de tests de qualité des données.
- Documentation et versionnement avec **Git et GitHub**.
- Restitution **Power BI en cours de développement**.

**Technologies :** Python, SQL, GCP, BigQuery, dbt, Git, GitHub, Power BI.
